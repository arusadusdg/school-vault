# W9 - Discussion – Is Programming Always the Solution?

Computational thinking is not limited to writing code. It provides a toolkit for understanding a problem, identifying what matters, recognising patterns, breaking a complex problem into manageable parts and developing a logical approach to a solution. These techniques can be applied in areas such as software development, data analysis, machine learning, database design and network security.

**Discussion Prompt**

Consider the following claim:  
 “The most important part of solving a computer science problem happens before any code is written.”  
 To what extent do you agree with this claim?

* Explain how computational thinking can be used to approach a problem without immediately writing a program.
* Select one real-world context from software development, data analysis, machine learning, database design or network security. Explain how computational thinking could help identify and structure the problem before implementation.
* Discuss how at least two computational thinking techniques, such as abstraction, decomposition, pattern recognition or algorithmic design, could influence the quality of the eventual solution.
* Evaluate one possible consequence of beginning implementation before the problem has been adequately analysed.
* Reach a clear, supported conclusion about the extent to which effective problem solving in computer science depends on thinking before programming.

**Discussion Guidelines**

* Post one original response that addresses all parts of the prompt.
* Use appropriate computer science terminology and support your reasoning with a relevant example.
* Do not simply define computational thinking techniques. Apply them to the problem or context you select.
* Your conclusion should follow logically from the arguments presented.
* After posting, reply to at least two classmates.
* Each peer response must make a meaningful contribution. You may challenge an assumption, introduce another application, compare approaches, extend an argument, or ask a question that requires further reasoning.
* Replies such as “I agree”, “Good point” or a restatement of the original post do not count as meaningful contributions.
* Maintain a respectful and professional tone when questioning or challenging another viewpoint.
