# W21 - Assessment: Network Architecture

**Syllabus alignment:** A2.2.1 Network topologies, A2.2.2 Functions of servers, A2.2.3 Client-server and peer-to-peer networking models, and A2.2.4 Network segmentation.

**Total marks:** 20 marks

**Instructions**

* Answer all questions required for your level.
* Read each scenario carefully and apply networking concepts to the context provided.
* Respond according to the IB command term used in each question.
* Use appropriate computer science terminology. Where several factors are relevant, make clear links between the factor and the scenario.
* Answers that only list terminology without applying it to the given scenario may not receive full marks.

**Scenario**

Greenfield College is expanding from one building to a larger campus. The new campus will contain an administration building, two teaching blocks, a library, computer laboratories and student study areas. The college expects the number of connected devices to increase over the next five years. Staff require reliable access to shared files and online services, while students need controlled access to learning resources and the internet. The network team is also concerned about congestion, security and the ability to expand the network without redesigning it completely.

**Question 1 - Network Topologies [4 marks]**

Describe the suitability of star, mesh and hybrid topologies for Greenfield College. In your answer, refer to at least three of the following factors: reliability, transmission speed, scalability, data collisions and cost. [4]

**Question 2 - Level-specific question [4 marks]**

Greenfield College plans to use several dedicated servers. Describe the function of each of the following in the college network:  
a. DNS server  
b. DHCP server  
c. file server  
d. proxy server. [4]

**Question 3 - Networking Models [4 marks]**

The college must choose how users will access shared files and services.

Compare the client-server and peer-to-peer networking models for this purpose. Refer to both models throughout your answer and include at least one benefit and one drawback of each. [4]

**Question 4 - Network Segmentation [4 marks]**

The network team proposes separating administration, teaching laboratories, staff devices and student devices into different logical network areas.

Explain how network segmentation could improve both performance and security at Greenfield College. Your response must include the roles of subnetting and VLANs. [4]

**Question 5 - Integrated Network Decision [4 marks]**

A new computer laboratory will contain 40 desktop computers. It must provide reliable access to shared resources, reduce unnecessary traffic from student wireless devices elsewhere on campus, and remain easy to expand later.

Justify a suitable network design for the laboratory. Your answer should refer to:

* an appropriate topology
* an appropriate networking model
* one use of segmentation, subnetting or a VLAN

You must explain why each choice is appropriate for the scenario. [4]

**Total: 20 marks**
