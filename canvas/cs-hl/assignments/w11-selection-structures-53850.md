# W11 - Selection Structures

**Topics:** if, else, else if / elif, relational operators, Boolean operators, nested/combined conditions, switch/case, selecting appropriate selection structures.

**Instructions**

* Answer all questions.
* Read each question carefully and respond according to the IB command term used.
* Use the programming language currently being studied in your class. Use else if in Java or elif in Python, as appropriate.
* For the switch/case question, use Java-style switch/case as specified in the course content.
* Use appropriate indentation, programming terminology and conventions.
* Where you construct code, logically equivalent solutions should produce the required result for all stated cases.
* Total marks: 15.

**Questions**

(a) State the output produced by the following code when score = 72. [1]

IF score >= 50  
 OUTPUT "Pass"  
 ELSE  
 OUTPUT "Not achieved"  
 END IF

(b) Trace the following selection structure when temperature = 28 and state the output. [2]

IF temperature > 30  
 OUTPUT "Hot"  
 ELSE IF temperature >= 20  
 OUTPUT "Warm"  
 ELSE  
 OUTPUT "Cool"  
 END IF

(c) Construct a selection structure that inputs a student's mark and outputs:

"Excellent" if the mark is 80 or above  
"Satisfactory" if the mark is from 50 to 79 inclusive  
"Needs improvement" if the mark is below 50. [3]

(d) A school activity is open only to students who are at least 14 years old AND have submitted parental permission.

     Construct a selection structure that inputs age and permission status and outputs either "Eligible" or "Not eligible". [3]

(e) A menu program accepts an integer choice from 1 to 3:

1 = View profile  
 2 = Edit profile  
 3 = Log out

     Construct a switch/case structure that outputs the appropriate option. Include a default case that outputs "Invalid choice". [3]

(f) A program must classify a numerical examination score into several ranges. Explain why an if / else if / else structure is more appropriate than a switch/case structure for this problem. [3]

**Total Marks: 15**
