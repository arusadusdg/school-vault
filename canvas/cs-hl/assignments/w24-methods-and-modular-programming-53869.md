**Scenario: Student Performance Management System**

A school is developing a Student Performance Management System. The programmer has already created methods to avoid repeating code. The development team wants to extend the system while maintaining good programming practices.

**Existing code:**

public static double calculateAverage(int mark1, int mark2, int mark3)  
 {  
 return (mark1 + mark2 + mark3) / 3.0;  
 }  
  
 public static boolean isPassed(double average)  
 {  
 return average >= 50;  
 }

**Assessment Questions**

1. Define the term method. [1]
2. Explain two advantages of using methods in programming. [2]
3. Evaluate writing all program logic inside one main program instead of using methods. [3]
4. Distinguish between the scope of a global variable and a local variable. [2]
5. Construct a method called calculateGrade(). The method should receive average mark and return A, B, C, D or F according to the grade boundaries provided. [5]
6. Construct a method called displayResult(). The method should receive student name and average mark, use isPassed(), and display whether the student passed or failed. [4]
7. Rewrite the following program using appropriate methods to improve modularity. [3]
8. Discuss why modularization is important when developing large software systems. Consider maintenance, testing, code reuse and teamwork. [5]
