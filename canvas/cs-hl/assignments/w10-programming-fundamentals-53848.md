# W10 - Programming Fundamentals

**Topics:** programming tokens, sequence of instructions, impact of instruction order, avoiding programming errors, simple input/output, calculations, constructing simple programs.

**Instructions**

* Answer all questions.
* Read each question carefully and respond according to the IB command term used.
* Use appropriate programming terminology and conventions.
* Show the required instructions or working where a question asks you to construct or correct a program.
* Assume the pseudocode shown in the questions executes sequentially from top to bottom unless otherwise stated.

**Questions**

1. Identify two different types of programming tokens that may appear in a program. [2]
2. State the output produced by the following instructions when price = 8 and tickets = 3. [1]  
   total = price \* tickets  
    OUTPUT total
3. Explain why the order of instructions is important in the following program. [3]  
    OUTPUT total  
    total = price \* tickets
4. Construct an algorithm that:
   * inputs the student's name
   * inputs the number of tickets required
   * inputs the price of one ticket
   * calculates the total cost
   * outputs the student's name and the total cost. [4]
5. A programmer writes the following algorithm to calculate the area of a rectangle.  
    INPUT length  
    INPUT width  
    area = length + width  
    OUTPUT area  
    Identify the error and construct the corrected instruction. [2]
6. Explain two ways in which a programmer can reduce the likelihood of errors when constructing a program. [3]
