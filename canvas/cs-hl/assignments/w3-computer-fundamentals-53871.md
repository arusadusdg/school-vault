# W3 - Computer fundamentals

**Assessment overview**

This assignment is designed in the style of a structured **IB Computer Science Paper 1 question**. It uses a single real-world scenario followed by connected subquestions of increasing demand, where students respond to short-answer questions using command terms such as **state, describe, list, and explain**.

The assessment covers: CPU components and registers, address, data and control buses, primary memory, cache hits and cache misses, the fetch-decode-execute cycle, CPU and GPU architecture, and cooperation between CPUs and GPUs.

**Submission guidelines**

1. Answer **all parts** of the question.
2. Write each answer in the space provided beneath the relevant subquestion.
3. Pay close attention to the **IB command term** and the number of marks available.
4. Use accurate computer science terminology, including the names of registers, buses and processor components.
5. Give distinct points where a question asks for more than one answer.
6. For an **explain** question, do not only identify or describe a feature. Develop the answer by showing how or why it produces an outcome.
7. For an **evaluate** question, consider both strengths and limitations before reaching a supported conclusion.
8. Diagrams may be used where they improve the clarity of an answer, but they must be correctly labelled.
9. Submit your work in the format specified on the course page.
10. Your submission must be your own work.

**Question 1**

A medical research centre uses a computer system to analyse large numbers of medical images. The system contains a multi-core CPU, a GPU, RAM and several levels of cache memory.

(a) State the register that stores the address of the next instruction to be fetched. [1]

(b) Outline the role of the memory address register and the memory data register when an instruction is fetched from memory. [2]

(c) Describe the role of each of the following buses during the fetching of an instruction:

* + - * address bus
      * data bus
      * control bus [3]

(d) Explain how cache memory can improve the performance of the computer system. In your answer, refer to cache hits and cache misses. [4]

(e) Evaluate the use of a CPU and a GPU working together to analyse a large collection of medical images. [5]

**Total: [15 marks]**
