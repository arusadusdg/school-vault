# W4 - Data Representation and Logic Gates

**Assessment context**

A wildlife research station uses a digital monitoring system. Sensors record identification codes, text labels, photographs and audio. A control circuit uses logic gates to decide when an alert should be sent. The system displays some stored values in hexadecimal so that technicians can inspect them more easily.

**Submission requirements**

1. Answer all parts, (a) to (e).
2. Write each response directly below the word Answer.
3. Show all relevant stages of working for conversion questions. A correct answer without working may not receive full credit when the command term is calculate.
4. Use the exact number of distinct points suggested by the mark allocation. As a guide, a 3-mark response normally requires three relevant points or a developed explanation containing equivalent detail.

**Question 1**

The system stores the decimal identification number 45 as an unsigned binary integer.

**(a) Calculate the binary representation of the decimal integer 45. Show your working. [2]**

**(b) Calculate the hexadecimal representation of the binary integer 10111100. Show your working. [2]**

**(c) Describe how a digital photograph is represented in binary. [3]**

**(d) Construct a complete truth table for the Boolean expression Alert = M AND (T OR S). [4]**

**(e) Explain how these changes would affect the quality and storage requirements of the photographs and audio recordings. [4]**
